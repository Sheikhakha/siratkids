# SiratKids - Team Roles

## Overview

| Role | Short Name | Focus |
|------|------------|-------|
| Owner | Owner | Vision, priorities, final sign-off |
| Func Lead | Func | Requirements, workflows, coordination |
| Frontend | FDev | HTML/CSS/JS implementation |
| UI Tester | UI | Visual QA, alignment, spacing |
| Browser QA | BQA | Cross-browser, mobile testing |
| Arabic Rev | Arabic | Arabic text, diacritics, Islamic content |

---

## Role Definitions

### Owner
- Sets project vision and priorities
- Makes final decisions on features and content
- Approves releases and sign-off
- Stakeholder communication

### Func Lead
- Translates requirements to technical specs
- Designs workflows and user journeys
- Coordinates between all team members
- Manages task priorities and deadlines

### FDev (Frontend Developer)
- HTML/CSS/JS implementation
- Responsive design and RTL support
- Arabic font integration (Noto Naskh, Indopak Nastaleeq)
- localStorage and user preferences
- Accessibility improvements (ARIA, lang attributes)

### UI Tester
- Visual inspection of all pages
- Layout alignment and spacing checks
- RTL/LTR text rendering consistency
- Font size controls verification
- Sidebar navigation functionality
- Mobile layout validation

### BQA (Browser QA)
- Browser compatibility (Chrome, Firefox, Safari, Edge)
- Mobile device testing (iOS, Android)
- CSS feature support (backdrop-filter, gradients)
- Performance and load time checks
- Responsive breakpoint validation

### Arabic Rev (Arabic Reviewer)
- Arabic text authenticity and diacritics
- Islamic content accuracy (Tawheed, Hadith)
- Translation quality (English, Arabic, Tamil)
- Transliteration review
- Quranic verse and hadith verification

---

## Workflow

1. **FDev** implements feature
2. **UI** checks visual quality
3. **BQA** verifies cross-browser compatibility
4. **Arabic** validates Arabic/Islamic content
5. **Func** coordinates reviews and approvals
6. **Owner** final sign-off
